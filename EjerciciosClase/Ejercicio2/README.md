#Ejercicio 3 – Tres Calificaciones

Este ejercicio consiste en analizar, diseñar y representar un programa que permita:
- Ingresar tres calificaciones.
- Calcular el promedio.
- Determinar si el estudiante está **APROBADO** o **REPROBADO** según el promedio.
- Mostrar los resultados en pantalla.
