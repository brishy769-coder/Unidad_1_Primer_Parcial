Ejercicio 1 – Registro de Estudiante

Este ejercicio consiste en analizar, diseñar y representar un programa que permita:
- Registrar datos básicos de un estudiante.
- Calcular el promedio de sus notas.
- Convertir la edad a binario y hexadecimal.
- Mostrar los resultados en pantalla.
