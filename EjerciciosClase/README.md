Ejercicio: Intercambio de Variables

Este ejercicio muestra cómo **intercambiar los valores de dos variables** usando una variable auxiliar.  
Incluye análisis, algoritmo, flujograma, pseudocódigo, prueba de escritorio y codificación en **Java** y **C++**.

```text
Valores iniciales:

B = 12

--- Resultados ---
